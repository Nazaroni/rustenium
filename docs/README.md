# Rustenium Documentation

Rustenium is a Rust-native, async-first end-to-end automation library for web,
iOS, and Android applications. Inspired by Selenium and Appium, it provides
a unified, high-performance, and type-safe API for browser and mobile automation.

## Getting Started

- Install required drivers (e.g., chromedriver, geckodriver, Appium server)
- Add Rustenium to your `Cargo.toml`
- See `/examples` for usage

## Features

- Async-first, safe API
- Web automation via W3C WebDriver (Chrome, Firefox, Safari)
- Mobile automation via Appium (iOS, Android)
- High-level element interactions, waits, assertions
- Extensions: Grid, BiDi, screenshot, logging, POM helpers
