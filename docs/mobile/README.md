# Mobile Automation

The `mobile` crate enables automation of Android and iOS applications using
Rustenium-mobile.

## Modules

- **Android**: Specific capabilities and commands for Android automation.
- **iOS**: Specific capabilities and commands for iOS automation.

## Features

- **App Management**: Install, launch, and terminate apps.
- **Touch Actions**: Tap, swipe, and perform multi-touch gestures.
- **Device Control**: Rotate screen, toggle network settings.

## Setup

Ensure you have the Rustenium-mobile server running and the necessary drivers
(UiAutomator2 for Android, XCUITest for iOS) installed.
